# FocusType

A simple productivity web application that combines a typing speed test with a focus timer.

## Features

### Typing Speed Test
- Multiple text categories
- 30, 60, and 120-second test options
- Words Per Minute (WPM) calculation
- Typing accuracy measurement
- Correct and incorrect character highlighting
- Best WPM tracking

### Focus Timer
- Focus and short break modes
- Custom timer durations
- Start, pause, and reset controls
- Completed focus session tracking

### Statistics
- Best typing speed
- Average typing accuracy
- Total focus minutes
- Completed focus sessions
- Weekly activity chart

## Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage

## Purpose

This project was created to practice front-end development, JavaScript logic, and user interface design.
